## 2. 制作链路（可复现）

1. **终端实录**：用 `dev_runs/demo_slow.sh`（放慢节奏版，每步之间停顿 2-7s）。踩坑记录：`screencapture` 的全屏模式会被前台应用抢焦点（第一次录制拍成了 ZCode 窗口，作废）；改成**按窗口 ID 录制** `screencapture -v -l<WID>` 后就与焦点无关。另外 macOS 中文环境下 Quartz 看到的窗口属主名是「终端」不是 "Terminal"（这是第二次录出空结果的根因）。
2. **分段**：按 1fps（每秒取一帧）抽帧，靠 JPEG 文件大小的跳变定位出 5 步的边界（t≈12.6/23.6/31.6/40.6/49.6s）；比 scene 滤镜可靠（这个 ffmpeg build 上 select+metadata 没有输出）。
3. **卡片**：用 HTML+Playwright 截图生成（`/tmp/r2g_cards.html`），字体栈 PingFang/Hiragino，卡片上的数字与 experiment-report §2 逐字核对过。
4. **字幕**：用 ffmpeg drawtext（字体 Hiragino Sans GB），中文文本走 textfile 传入以避开转义问题；字体路径里带空格时，必须用过滤器内的单引号包住。
5. **拼接**：9 段素材统一转成 1920x1080@30 yuv420p，再用 concat demuxer 拼接并加 faststart。终端窗原始 3040x1786 → crop 3040:1710:0:76（裁掉标题栏）→ 缩放到 1080p。
